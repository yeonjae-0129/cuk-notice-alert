# 가대알림

가톨릭대학교 전체 공지에서 관심 키워드와 일치하는 새 글을 휴대폰 푸시로 받는 경험을 보여주는 웹 목업입니다.

## 핵심 흐름

1. 실제 계정 정보를 입력하지 않는 학교 계정 로그인 체험
2. 알림 설정 페이지에서 `장학`, `인턴` 등 관심 키워드 등록
3. `최신 공지 확인하고 미리보기`를 눌러 실시간 미리보기 페이지로 이동
4. 일치 공지 또는 전체 최신 공지를 별도 목록 페이지에서 확인
5. 뒤로가기로 이전 페이지에 돌아가거나 공지를 눌러 공식 원문 확인

공개 공지 목록은 서버 API를 통해 공식 홈페이지에서 가져옵니다. 사용자가 브라우저 알림 권한을 허용하면 서비스 워커와 Web Push로 실제 기기 알림을 받을 수 있습니다. 학교 계정 로그인은 화면 시연이며, 공식 홈페이지 연결 실패 시 샘플 공지를 명시해 표시합니다.

## 실제 푸시 구성

1. `.env.example`을 참고해 VAPID 키, Supabase 서버 키, `CRON_SECRET`을 설정합니다.
2. Supabase SQL 편집기에서 `supabase/migration.sql`을 실행합니다.
3. Vercel에 같은 환경 변수를 설정하고 HTTPS로 배포합니다.
4. GitHub 저장소 비밀에 배포 주소 `APP_URL`과 같은 `CRON_SECRET`을 등록합니다.
5. 앱에서 `알림 권한 켜기`를 누르고 `테스트 푸시`로 실제 도착을 확인합니다.

예약 작업은 5분마다 최신 공지를 확인합니다. 새 공지의 제목·분류·작성 부서 중 키워드가 하나라도 일치하면 최대 3건을 발송하며, 이미 처리한 공지는 다시 보내지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run build
```

로그인부터 공지 상세까지의 클릭 흐름, 빈 값·중복 키워드·결과 없음 상태, 390px 모바일과 1440px 데스크톱 화면을 확인했습니다. 실제 기기 푸시는 HTTPS 배포와 영구 DB 연결 후 최종 확인합니다.
