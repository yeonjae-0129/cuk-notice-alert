# 가대알림

가톨릭대학교 전체 공지에서 관심 키워드와 일치하는 새 글을 휴대폰 푸시로 받는 경험을 보여주는 웹 목업입니다.

## 핵심 흐름

1. 실제 계정 정보를 입력하지 않는 학교 계정 로그인 체험
2. `장학`, `인턴` 등 관심 키워드 등록
3. 새 공지 도착 시연과 휴대폰 푸시 확인
4. 푸시를 눌러 일치 키워드와 공지 상세 확인

모든 로그인, 공지, 푸시는 로컬 샘플 데이터로 동작하며 실제 학교 시스템과 연결되지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run build
```

로그인부터 공지 상세까지의 클릭 흐름, 빈 값·중복 키워드·결과 없음 상태, 390px 모바일과 1440px 데스크톱 화면을 확인했습니다.
